# 택시미터

GPS 이동 거리와 시간으로 요금을 계산하는 간단한 택시미터 웹앱(PWA)입니다.

- 사이트: https://ksg-ksg.github.io/taxi/
- 안드로이드 크롬에서 열고 메뉴의 **홈 화면에 추가(앱 설치)** 를 누르면 앱처럼 쓸 수 있습니다.

## 사용법

| 칸 | 기능 |
|---|---|
| 빈차 / 운행 | 누르면 운행 시작. 운행 중에는 두 번 눌러 종료 |
| 할증 | 할증(기본 20%) 켜기/끄기. 심야 할증은 시간에 따라 자동 적용 |
| 주행 | 현재 상태 표시: 대기 / 거리요금 / 저속·시간요금 / GPS 약함 |
| 지불 | 지금까지 금액으로 영수증 발행 (운행 중이면 중간 정산) |

하단 버튼: 왼쪽 = 오늘 운행 기록, 가운데 길게 누르기 = 설정, 오른쪽 = 창 닫기

## 요금 (서울 중형택시 기준 기본값, 설정에서 변경 가능)

- 기본요금 4,800원 (1.6km)
- 이후 131m마다 100원
- 시속 15.72km 미만·정차 중에는 30초마다 100원 (시간·거리 병산)
- 심야 할증: 22~23시·02~04시 20%, 23~02시 40%

## 알아둘 점

- 브라우저 앱이라 화면이 꺼지거나 다른 앱으로 넘어가면 GPS 측정이 멈춥니다. 운행 중에는 화면 꺼짐을 막아 둡니다.
- 진행 중인 운행과 기록은 기기 브라우저에 저장됩니다. 새로고침해도 이어서 계산합니다.
- 설정의 **시뮬레이션 모드**로 실제로 움직이지 않고도 테스트할 수 있습니다.
